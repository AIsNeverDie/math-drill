## 架构重构说明 (i18n Architecture Refactor)

原版项目为每种语言单独维护了一整套完全重复的 HTML/CSS/JS 代码（例如 `src/en/`、`src/ja/`、`src/zh-CN/` 等目录下各自包含完整的数十个 JS 脚本）。这种多分支复制粘贴模式导致业务逻辑迭代极为困难，修一个 Bug 或改动一个公式需要手动同步四份代码，且极易出现国际化遗漏。

我们在本次版本中对其进行了**现代单源 i18n 架构重构**：
1. **单一核心源码 (Single Source of Truth)：** 将全部游戏主循环、逻辑判定、音效与生成算法统一收敛到 `src/core/js/`，核心代码只维护一份。
2. **纯净字典分离 (Key-Value Locales)：** 各语言（`en`, `ja`, `zh-CN`, `zh-TW`）仅维护纯净的 `src/locales/*.json` 键值对翻译字典，彻底将「业务逻辑」与「文案本地化」解耦。
3. **极速自动化编译 (Automated Build & Minify)：** 引入轻量级 `tools/build.mjs`（基于 esbuild），在构建时自动将对应语言词库注入核心代码并压缩，一键输出开箱即用的静态应用到 `app/`。

## 这是什么？

一款面向小学 1–6 年级学生的浏览器数学练习游戏。它看起来像游戏、玩起来像游戏，顺便还学会了算术。

孩子们在**技能树**中解锁 58 项数学技能，从个位数加法一路练到分数、比例和竖式除法。系统会追踪已掌握、已生锈和即将学习的内容，自动匹配适合当前水平的题目。

## 核心功能

| 功能 | 说明 |
|:-----|:-----|
| 🌳 **技能树** | 6 个年级共 58 项技能，含前置依赖关系 |
| 📅 **每日任务** | 每天 3 个目标，按当前水平自动匹配 |
| 🔥 **连击系统** | 快速连续答对可将得分倍率提升至 ×2 |
| ⏱️ **加时赛** | 首次正确率 ≥80% 解锁，限时 90 秒冲分 |
| 🏆 **300+ 奖杯** | 速度、准确率、连打、里程碑等各类成就 |
| 🎒 **图鉴收藏** | 通过奖杯解锁专属形象道具 |
| 📦 **时光胶囊** | 练习满 30 天后，重温最初做过的第一道题 |
| 📈 **成长记录** | 每项技能的星级、速度记录与记忆保留率 |
| 🔐 **离线优先** | 无需账号，所有进度保存在浏览器本地 |

## 游戏流程

```
主页 → 开始练习 → 答 10 道题（基础关）
     → 结算页 → 加时赛已解锁？→ 90 秒冲分
     → 最终得分 → 奖杯 & 技能新闻 → 主页
```

每道题由**自适应引擎**选出：综合考虑间隔重复、近期错题、技能前置依赖和连击状态，在正确时机给出正确挑战。

## 技术栈

- **原生 JavaScript 与模块化架构** —— `src/core/` 统一单源维护，纯净键值对多语言国际化系统。
- **极速构建与轻量压缩** —— 基于 `esbuild` 自动压缩生成最终部署文件至 `app/`。
- **CSS 自定义属性** —— 按语言动态管理主题与排版字体变量。
- **`localStorage`** —— 客户端完全离线，所有游戏进度保存在本地。
- **Node.js 内置测试运行器** —— 67 个自动化单元测试，覆盖算术生成、分级测试、积分连击与 i18n 完整性。

```
math-drill/
├── src/
│   ├── core/           # 核心代码唯一真实来源（HTML、CSS、JS）
│   │   ├── index.html
│   │   ├── css/
│   │   └── js/
│   └── locales/        # 纯净多语言词库（en, ja, zh-CN, zh-TW）
├── app/                # 构建输出目录（用于静态部署）
│   ├── index.html      # 语言路由入口
│   ├── en/             # 英文版
│   ├── ja/             # 日文版
│   ├── zh-CN/          # 简体中文版
│   └── zh-TW/          # 繁体中文版
├── tests/              # 67 个单元测试（Node 内置运行器）
└── tools/              # 构建与字体脚本
    ├── build.mjs       # 多语言 esbuild 编译脚本
    └── dev_server.mjs  # 本地开发服务
```

## 语言与字体

每种语言独立使用自己的字体子集，绝不混用：

| 语言 | 粗体字体 | 正文字体 |
|:-----|:---------|:---------|
| English  | Dela Gothic One | Zen Maru Gothic |
| 日本語   | Dela Gothic One | Zen Maru Gothic |
| 简体中文 | Dela Gothic One / ZCOOL KuaiLe | PingFang SC / 微软雅黑 |
| 繁體中文 | Dela Gothic One / ZCOOL KuaiLe | PingFang TC / 微軟正黑體 |

字体子集按语言从游戏实际文本生成，只打包游戏中真正出现的字形。

## 本地运行

```bash
# 1. 安装开发依赖 (esbuild)
npm install

# 2. 编译生成静态应用
npm run build

# 3. 启动本地开发服务
npm run dev
# 或使用静态服务器: python3 -m http.server 8000 -d app
# → 打开 http://localhost:8000
```

## 重新生成字体

如果添加了新文本（新技能、新 UI 字符串），需重新生成字体子集：

```bash
bash tools/build_fonts.sh
# 从 Google Fonts 下载源字体，按语言切割子集，输出 WOFF2
```
