# 🧮 数学特训

> 让孩子越玩越开心的小学数学练习游戏 —— 连击、奖杯、打卡、时光胶囊，加时赛限时冲分。

**🇺🇸 [English](README.md) · 🇯🇵 [日本語](README.ja.md) · 🇨🇳 简体中文 · 🇹🇼 [繁體中文](README.zh-TW.md)**

---

## 这是什么？

一款面向小学 1–6 年级学生的浏览器数学练习游戏。它看起来像游戏、玩起来像游戏，顺便还学会了算术。

孩子们在**技能树**中解锁 58 项数学技能，从个位数加法一路练到分数、比例和竖式除法。系统会追踪已掌握、已生锈和即将学习的内容，自动匹配适合当前水平的题目。

---

## 核心功能

| 功能 | 说明 |
|:-----|:-----|
| 🌳 **技能树** | 6 个年级共 58 项技能，含前置依赖关系 |
| 📅 **每日任务** | 每天 3 个目标，按当前水平自动匹配 |
| 🔥 **连击系统** | 快速连续答对可将得分倍率提升至 ×2 |
| ⏱️ **加时赛** | 首次正确率 ≥80% 解锁，限时 90 秒冲分 |
| 🏆 **300+ 奖杯** | 速度、准确率、连打、里程碑等各类成就 |
| 🎒 **图鉴收藏** | 通过奖杯解锁专属形象道具 |
| 📦 **时光胶囊** | 练习满 30 天后，重温最初做过的第一道题 |
| 📈 **成长记录** | 每项技能的星级、速度记录与记忆保留率 |
| 🔐 **离线优先** | 无需账号，所有进度保存在浏览器本地 |

---

## 游戏流程

```
主页 → 开始练习 → 答 10 道题（基础关）
     → 结算页 → 加时赛已解锁？→ 90 秒冲分
     → 最终得分 → 奖杯 & 技能新闻 → 主页
```

每道题由**自适应引擎**选出：综合考虑间隔重复、近期错题、技能前置依赖和连击状态，在正确时机给出正确挑战。

## 技术栈

- **纯原生 JavaScript** —— 零框架、零构建步骤
- **ES 模块** —— 浏览器原生 import，无需打包器
- **CSS 自定义属性** —— 按语言管理主题与字体变量
- **`localStorage`** —— 所有进度存储在客户端本地
- **Node.js 内置测试运行器** —— 66 个单元测试，无需额外测试框架

```
app/
├── index.html          # 语言路由入口
├── en/                 # 英语版（独立完整）
├── ja/                 # 日语版
├── zh-CN/              # 简体中文版
├── zh-TW/              # 繁体中文版
│   ├── index.html
│   ├── style.css
│   ├── fonts/          # 按语言单独生成的 WOFF2 字体子集
│   └── js/
│       ├── main.js     # UI 与游戏主循环
│       ├── problems.js # 题目生成器（覆盖全部技能类型）
│       ├── skills.js   # 技能树与掌握度逻辑
│       ├── scoring.js  # 多帕与连击计算
│       ├── trophies.js # 成就目录
│       ├── quests.js   # 每日任务引擎
│       └── store.js    # localStorage 持久化
tests/                  # 66 个单元测试（Node 内置运行器）
tools/                  # 字体子集生成脚本
```

## 语言与字体

每种语言独立使用自己的字体子集，绝不混用：

| 语言 | 粗体字体 | 正文字体 |
|:-----|:---------|:---------|
| English  | Dela Gothic One | Zen Maru Gothic |
| 日本語   | Dela Gothic One | Zen Maru Gothic |
| 简体中文 | ZCOOL KuaiLe | PingFang SC / 微软雅黑 |
| 繁體中文 | ZCOOL KuaiLe | PingFang TC / 微軟正黑體 |

字体子集按语言从游戏实际文本生成，只打包游戏中真正出现的字形。

## 本地运行

无需安装，无需构建：

```bash
python3 -m http.server 8000 -d app
# → 打开 http://localhost:8000
```

---

## 运行测试

```bash
node --test tests/*.test.mjs
# 66 个测试，约 400ms
```

---

## 重新生成字体

如果添加了新文本（新技能、新 UI 字符串），需重新生成字体子集：

```bash
bash tools/build_fonts.sh
# 从 Google Fonts 下载源字体，按语言切割子集，输出 WOFF2
```
