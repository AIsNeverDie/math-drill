## 架構重構說明 (i18n Architecture Refactor)

原版專案為每種語言單獨維護了一整套完全重複的 HTML/CSS/JS 程式碼（例如 `src/en/`、`src/ja/`、`src/zh-CN/` 等目錄下各自包含完整的數十個 JS 腳本）。這種多分支複製貼上模式導致業務邏輯迭代極為困難，修復一個 Bug 或改動一個公式需要手動同步四份程式碼，且極易出現國際化遺漏。

我們在本次版本中對其進行了**現代單源 i18n 架構重構**：
1. **單一核心原始碼 (Single Source of Truth)：** 將全部遊戲主迴圈、邏輯判定、音效與生成演算法統一收斂至 `src/core/js/`，核心程式碼只維護一份。
2. **純淨字典分離 (Key-Value Locales)：** 各語言（`en`, `ja`, `zh-CN`, `zh-TW`）僅維護純淨的 `src/locales/*.json` 鍵值對翻譯字典，徹底將「業務邏輯」與「文案本地化」解耦。
3. **極速自動化編譯 (Automated Build & Minify)：** 引入輕量級 `tools/build.mjs`（基於 esbuild），在建置時自動將對應語言詞庫注入核心程式碼並壓縮，一鍵輸出開箱即用的靜態應用至 `app/`。

## 這是什麼？

一款面向小學 1–6 年級學生的瀏覽器數學練習遊戲。它看起來像遊戲、玩起來像遊戲，順便還學會了算術。

孩子們在**技能樹**中解鎖 58 項數學技能，從個位數加法一路練到分數、比例和直式除法。系統會追蹤已掌握、已生疏和即將學習的內容，自動匹配適合當前水準的題目。

---

## 核心功能

| 功能 | 說明 |
|:-----|:-----|
| 🌳 **技能樹** | 6 個年級共 58 項技能，含前置依賴關係 |
| 📅 **每日任務** | 每天 3 個目標，按當前水準自動匹配 |
| 🔥 **連擊系統** | 快速連續答對可將得分倍率提升至 ×2 |
| ⏱️ **加時賽** | 首次正確率 ≥80% 解鎖，限時 90 秒衝分 |
| 🏆 **300+ 獎杯** | 速度、正確率、連打、里程碑等各類成就 |
| 🎒 **圖鑑收藏** | 透過獎杯解鎖專屬形象道具 |
| 📦 **時光膠囊** | 練習滿 30 天後，重溫最初做過的第一道題 |
| 📈 **成長記錄** | 每項技能的星級、速度紀錄與記憶保留率 |
| 🔐 **離線優先** | 無需帳號，所有進度儲存在瀏覽器本機 |

## 遊戲流程

```
主頁 → 開始練習 → 答 10 道題（基礎關）
     → 結算頁 → 加時賽已解鎖？→ 90 秒衝分
     → 最終得分 → 獎杯 & 技能新聞 → 主頁
```

每道題由**自適應引擎**選出：綜合考量間隔重複、近期錯題、技能前置依賴和連擊狀態，在正確時機給出正確挑戰。

## 技術棧

- **原生 JavaScript 與模組化架構** —— `src/core/` 統一單源維護，純淨鍵值對多語言國際化系統。
- **極速建置與輕量壓縮** —— 基於 `esbuild` 自動壓縮生成最終部署檔案至 `app/`。
- **CSS 自訂屬性** —— 按語言動態管理主題與排版字型變數。
- **`localStorage`** —— 用戶端完全離線，所有遊戲進度儲存在本機。
- **Node.js 內建測試執行器** —— 67 個自動化單元測試，涵蓋算術生成、分級測試、積分連擊與 i18n 完整性。

```
math-drill/
├── src/
│   ├── core/           # 核心程式碼唯一真實來源（HTML、CSS、JS）
│   │   ├── index.html
│   │   ├── css/
│   │   └── js/
│   └── locales/        # 純淨多語言詞庫（en, ja, zh-CN, zh-TW）
├── app/                # 建置輸出目錄（用於靜態部署）
│   ├── index.html      # 語言路由入口
│   ├── en/             # 英文版
│   ├── ja/             # 日文版
│   ├── zh-CN/          # 簡體中文版
│   └── zh-TW/          # 繁體中文版
├── tests/              # 67 個單元測試（Node 內建執行器）
└── tools/              # 建置與字型指令碼
    ├── build.mjs       # 多語言 esbuild 編譯腳本
    └── dev_server.mjs  # 本機開發服務
```

## 語言與字型

每種語言獨立使用自己的字型子集，絕不混用：

| 語言 | 粗體字型 | 正文字型 |
|:-----|:---------|:---------|
| English  | Dela Gothic One | Zen Maru Gothic |
| 日本語   | Dela Gothic One | Zen Maru Gothic |
| 簡體中文 | Dela Gothic One / ZCOOL KuaiLe | PingFang SC / 微軟雅黑 |
| 繁體中文 | Dela Gothic One / ZCOOL KuaiLe | PingFang TC / 微軟正黑體 |

字型子集按語言從遊戲實際文字生成，只打包遊戲中真正出現的字符。

## 本機執行

```bash
# 1. 安裝開發依賴 (esbuild)
npm install

# 2. 編譯生成靜態應用
npm run build

# 3. 啟動本機開發服務
npm run dev
# 或使用靜態伺服器: python3 -m http.server 8000 -d app
# → 開啟 http://localhost:8000
```

## 重新生成字型

若新增了文字（新技能、新 UI 字串），需重新生成字型子集：

```bash
bash tools/build_fonts.sh
# 從 Google Fonts 下載來源字型，按語言切割子集，輸出 WOFF2
```
